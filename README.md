# Climate & Spatial Data Analysis

## Project Overview

This project investigates long-term temperature trends near Clemson, South Carolina, and geographic variations in ozone concentrations using R programming, time series analysis, and spatial statistical modeling.

The objective was to identify environmental patterns, evaluate statistical relationships, and explore methods for predicting environmental conditions.

## Research Questions

1. Are there statistically significant long-term temperature trends near Clemson, South Carolina?
2. How do seasonal patterns influence temperature measurements?
3. How can spatial statistical models estimate ozone concentrations at unobserved geographic locations?

## Methods and Techniques

**Time Series Analysis**
- Data cleaning and transformation
- Exploratory data analysis
- Linear regression and trend estimation
- Autocorrelation analysis
- ARMA and SARIMA modeling

**Spatial Data Analysis**
- Spatial data visualization
- Semivariogram analysis
- Spatial interpolation
- Gaussian process modeling

## Key Findings

- **Temperature Trends:** The analysis identified an estimated warming trend of approximately 0.047°C per year.
- **Seasonality:** Monthly temperature measurements exhibited strong seasonal patterns.
- **Spatial Modeling:** Gaussian process modeling demonstrated how ozone concentrations could be estimated at locations without direct measurements.
